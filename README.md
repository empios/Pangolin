# Pangolin Design System

Pangolin is an independent design-system study that combines an Ubuntu-flavored visual direction with Carbon-style product UI structure. It is a static HTML/CSS showcase with demo pages for dashboard, desktop, and mobile surfaces.

## Run locally

Open `index.html` in a browser. The demo pages live in `demos/`.

Because this is a static site, no build step is required.

## Project status

Pangolin is an independent design-system study. It is useful as a visual prototype, documentation artifact, and static UI reference. It is not yet a versioned production framework or package.
